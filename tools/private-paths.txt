# Paths that must never be pushed.

# One path per line, relative to the repo root. A trailing slash means a whole
# folder. Blank lines and # comments are ignored. Checked by
# tools/check-private-paths.sh, which the pre-push hook runs.
#
# This is the safety net, not the mechanism: .gitignore is what keeps these
# untracked in the first place. The guard catches the case where something got
# tracked anyway, by a git add -A, a force-add, or an earlier commit.
#
# A line starting with ! carves one path back out of a protected folder. The
# blunt folder rule above it stays, because that is what covers whatever private
# thing lands in the folder later. Prove both directions with:
#
#   ./tools/check-private-paths.sh --selftest
